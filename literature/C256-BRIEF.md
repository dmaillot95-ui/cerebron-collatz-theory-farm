Use this as prior-art guidance, not as proof.

1. Balanced/mechanical binary words are naturally modeled by Sturmian codings of irrational rotations. Return-word and first-return structure is therefore the correct established framework for the mechanical-code branch.
2. Current Collatz work on quasi-critical exponent codes motivates simultaneous consideration of Archimedean growth, the 2-adic start representative, and the terminal 3-adic representative.
3. Any imported theorem must be restated with exact hypotheses and independently checked before use.
4. Literature agreement is not evidence of arbitrary-N closure.
5. Search priority for theory agents: Sturmian return words, irrational rotations, continued fractions for log_2(3), 2-adic/3-adic coding constraints, and exact Collatz cycle equations.
